# Roadmap presentation

The browser presentation lives at `#roadmap`, following the app's existing hash
routing. It is linked from home and the lobby's upcoming-feature preview.

The page preserves Veilstrike's navy surfaces, muted gold accent, Nunito interface
text, Georgia fantasy display text, square geometry, and existing emblem. Design
dials: variance 7, motion 6, density 4. The new composition is a cinematic scene
with readable copy and a phase rail, rather than a document rendered as a table.

Three selectable phases show the current playable foundation, the next content
and progression phase, and later economy/mobile/event considerations. Artwork
comes from actual game renders and existing fighter portraits. Future scenes
use current arena imagery as atmosphere, not as evidence of released features.

Motion reveals each phase's artwork and content, and moves the selected phase
marker. The optional presentation advances every 18 seconds, with a pause button
and manual navigation. Selecting a phase pauses automatic advancement. Hidden
tabs suspend it; reduced-motion preferences disable automatic transitions and
retain manual access. Keyboard users can navigate the phase tabs with arrow keys,
Home, and End. On small screens the artwork becomes a header above the copy.

The page loads separately from combat. Direct roadmap entry does not prepare a
new arena renderer; a previously prepared lobby is hidden and paused while the
roadmap is open. Returning home or to the lobby retains the normal game flow.
