# Veilstrike

Veilstrike is an offline single-player 1v1 warrior fighting game. Choose a fighter,
learn their weapon style, and defeat an AI opponent across a best-of-three match.

## Gameplay

- Six selectable KayKit warriors with distinct weapons and abilities.
- 90-second rounds, best of three.
- Movement, jump, dash, dodge, block, parry, light/heavy attacks, specials, and ultimates.
- Responsive side-view combat with spacing, hit reactions, damage numbers, hit-stop,
  camera impact, particles, and entry/victory sequences.
- Three.js renders the arena and visible fighters; Phaser runs input and combat timing;
  Rapier provides the 3D physics foundation.

## Controls

`A/D` move, `W` jump, `SHIFT` dash, `J` light attack, `K` heavy attack, `L` block,
`U` special ability, `I` ultimate.

## Run

```bash
npm install
npm run dev
```
