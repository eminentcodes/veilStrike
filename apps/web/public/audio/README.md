# Veilstrike Audio Assets

The fight audio service uses Howler and loads these optional, licensed files:

- `battle-theme.mp3`
- `ui-click.mp3`
- `weapon-swing.mp3`
- `body-hit.mp3`
- `heavy-impact.mp3`
- `metal-clash.mp3`
- `parry.mp3`
- `dodge.mp3`
- `round-start.mp3`
- `fight-call.mp3`
- `victory.mp3`
- `defeat.mp3`

Place files obtained under a compatible license in this folder. Missing files fail
silently and do not stop combat. Do not commit copyrighted downloads without a license.
